Clock Plan 2 — راهنمای نصب روی GitHub Pages
===========================================
این نسخه تازه بر اساس ظاهر ساعت تصویری بازطراحی شده است. چون کد کامل نسخه قبلی در دسترس نبود، این فایل‌ها جایگزین مستقل محسوب می‌شوند، نه ویرایش سورس قبلی. اگر اطلاعات مهم در برنامه فعلی دارید، قبل از جایگزینی از آن نسخه بکاپ بگیرید. اطلاعات محلی قدیمی به این نسخه خودکار منتقل نمی‌شوند.

قابلیت‌ها:
- نمایش تاریخ شمسی (جلالی) و ساعت زنده
- انتخاب ساعت و ثبت برنامه با مدت و وضعیت انجام
- شروع روز جدید رأس ساعت ۲ بامدادِ زمان محلی گوشی؛ برنامه‌های قبلی پاک نمی‌شوند
- دیدن روزهای قبل/بعد و برنامه‌های هر روز
- ثبت مطالعه با تایمر یا دستی، جمع روز/هفته (شنبه تا جمعه)/ماه شمسی
- حلقه پیشرفت حول ساعت نسبت به هدف روزانه قابل تنظیم
- ذخیره محلی، خروجی JSON و بازیابی پشتیبان
- فایل‌های PWA برای بارگذاری آفلاین از دومین بار به بعد

نحوه انتشار:
1) وارد GitHub و مخزن Clock-plan شوید.
2) قبل از هر تغییر، از فایل‌های قبلی و اطلاعات خود نسخه پشتیبان بگیرید.
3) فایل‌های index.html، app.js، style.css، manifest.webmanifest، sw.js، .nojekyll و پوشه icons را در ریشه مسیر انتشاری سایت قرار دهید.
4) Commit changes بزنید؛ پس از انتشار سایت را باز و دوباره بارگذاری کنید.
5) در Chrome گزینه Install app را (در صورت نمایش) انتخاب کنید؛ این نسخه standalone است و برای نصب به شکل PWA نوار آدرس ندارد. اجرای آفلاین پس از حداقل یک‌بار بارگذاری آنلاین میسر است.
6) اگر با PWABuilder فایل APK می‌خواهید، خروجی جدید بگیرید و با همان کلید امضای قبلی Sign کنید (package ID و versionCode برای آپدیت باید رعایت شوند).

حذف نوار بالای APK ساخته‌شده با PWABuilder:
این نوار خود صفحه وب نیست؛ نوار Chrome Custom Tab ناشی از احراز هویت نشدن TWA است. برای حذف آن باید origin سایت با package name و اثر انگشت SHA-256 گواهیِ همان APK امضاشده از طریق Digital Asset Links تأیید شود.
فایل https://mimmansouriii-art.github.io/.well-known/assetlinks.json باید در ریشه دامنه وجود داشته باشد (معمولاً در مخزن جداگانه mimmansouriii-art.github.io نه در مسیر Clock-plan). فرمت نمونه داخل فایل assetlinks.EXAMPLE.json همین پوشه است؛ مقدارهای نمونه را با شناسه و اثر انگشت واقعی خودتان عوض کنید.
بدون این تأیید، حالت TWA ممکن است نوار بالای برنامه را نشان دهد. یک راه جایگزین، نصب مستقیم سایت به عنوان PWA از منوی Chrome است.

نکات داده:
- اطلاعات برنامه داخل localStorage همین origin/مرورگر نگهداری می‌شود و همگام‌سازی سروری ندارد.
- تایمر در صورت بسته شدن مرورگر همچنان بر اساس زمان واقعی هنگام بازشدن ادامه محاسبه می‌شود و وقتی پایان بزنید ثبت می‌شود.
- اگر تایمر از ۲ بامداد عبور کند، مدت ثبت‌شده بین دو روز تقسیم می‌شود.
- پاک‌کردن داده‌های Chrome/اپ، جابه‌جایی مرورگر یا حذف آن ممکن است اطلاعات را حذف کند؛ دوره‌ای Export JSON بگیرید.
- اگر رنگ، شکل یا منطق نسخه قدیمی باید کاملاً حفظ شود، لازم است ZIP سورس قبلی نیز در اختیار باشد.
