Clock Plan نسخه ۳
- روی عدد ساعت بزن.
- داخل پنجره، «صبح / AM» یا «شب / PM» را انتخاب کن.
- برای هرکدام می‌توانی چند برنامه جداگانه اضافه، تیک، ویرایش یا حذف کنی.
- ساعت واقعی از زمان دستگاه خوانده می‌شود.
- برنامه‌ها روی همان دستگاه ذخیره می‌شوند.

نصب PWA: فایل‌ها را روی میزبان HTTPS منتشر کن، سپس با مرورگر باز کن. اندروید: Chrome > Install app. آیفون: Safari > Share > Add to Home Screen.
اگر فایل را مستقیم از داخل پیش‌نمایش ZIP باز کنی، بعضی مرورگرها اجرای جاوااسکریپت را محدود می‌کنند؛ ابتدا استخراج کن و فایل را در مرورگر باز کن، یا آن را روی HTTPS میزبانی کن.
